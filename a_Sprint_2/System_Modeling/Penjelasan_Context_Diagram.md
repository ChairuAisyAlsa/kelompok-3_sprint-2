# Penjelasan Context Diagram

## 1. Tujuan
Context Diagram dibuat untuk menggambarkan batas sistem ClosetGirls ThriftShop serta hubungan antara sistem dengan pihak yang berinteraksi langsung dengannya.

## 2. Pembeli
Pembeli berinteraksi dengan sistem untuk melakukan registrasi, login, pencarian produk, melihat katalog dan detail produk, mengelola keranjang, melakukan checkout, serta mengelola profil. Sistem memberikan informasi akun, produk, katalog, hasil pencarian, detail produk, keranjang, dan konfirmasi checkout kepada pembeli.

## 3. Admin
Admin berinteraksi dengan sistem untuk melakukan pengelolaan produk. Sistem memberikan informasi produk kepada admin.

## 4. Sistem ClosetGirls ThriftShop
Sistem menjadi pusat pengolahan data dan informasi antara Pembeli dan Admin. Semua proses interaksi Pembeli dan Admin dilakukan melalui sistem ClosetGirls ThriftShop.

## 5. Kesimpulan
Context Diagram menunjukkan hubungan antara Pembeli, Admin, dan Sistem ClosetGirls ThriftShop melalui aliran data yang masuk dan keluar dari sistem. Diagram ini menjadi gambaran awal untuk memahami interaksi sistem sebelum membuat diagram pemodelan berikutnya.
